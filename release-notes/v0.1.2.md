# 灵狐工坊 v0.1.2

这是针对 v0.1.1 安装包的缺陷修复版。建议已安装 v0.1.1 的用户改用本版本。

## 请下载哪个文件

### FoxForge-0.1.2-Setup.exe

**普通用户请只下载这一个文件。** 这是 Windows 64 位 NSIS 安装包。

- 按向导安装：可以改安装目录，也可以选择仅为当前用户、或为这台电脑的所有用户安装（所有用户通常需要管理员权限）。
- 安装包内已包含：FFmpeg / ffprobe、LibreOffice（无界面 soffice）、Poppler（pdftoppm / pdftotext）、qpdf、Tesseract（简体中文 chi_sim + 英文 eng）、Pandoc、LibRaw（dcraw_emu）、Calibre（ebook-convert）、Sharp 图片引擎，以及人声分离用的 Demucs（CPU）与 UVR · MDX-Net（ONNX 模型）。
- 体积约 **1.23 GiB**（1,316,853,261 字节），与 v0.1.1 基本相当。
- 「特殊音乐模块」仍是可选功能，不会变成就绪，也不会打进安装包。首次使用 Demucs 时，如本机还没有对应模型权重，可能还会再下载一次。
- 安装包尚未做代码签名，Windows 可能弹出 SmartScreen 提示，选择「仍要运行」即可。

### FoxForge-0.1.2-Setup.exe.blockmap

分块校验文件，给自动更新使用。**手动安装不用下载。**

### latest.yml

自动更新元数据。**手动安装不用下载。**

## 此版本修复了什么

v0.1.1 其实已经把 Poppler 和 qpdf 打进了安装包，但官方压缩包多了一层版本目录，程序没有找到它们，设置页会显示「未接入」，引擎计数停在 7/10。现在会理顺安装布局，并且在这两个工具的目录树里按文件名继续查找，PDF 转图片、抽文本、加密和解密可以正常使用。

空拖放区、标题栏和关于页里的吉祥物「灵灵」在安装后会变成破碎的文件图标。原因是界面用了以 `/` 开头的图片地址，用 `loadFile` 打开时无法加载。现已改为相对路径，灵灵会正常显示。

把视频转成 MOV（以及其它由 FFmpeg 写出的格式）时，程序先写到一个 `.mov.part` 临时文件，FFmpeg 无法从这种扩展名判断封装格式，转换会失败。现在临时文件会保留真实扩展名（例如 `video.part.mov`），并显式指定输出格式，转换可以完成。
