# 灵狐工坊 v0.1.1

Windows 安装包现已**内置全部转换引擎**，安装后即可使用，不必再自行安装 FFmpeg、LibreOffice、Poppler、Tesseract 等工具。系统 PATH 里已有的同名工具仅作为后备。

## 请下载哪个文件

### FoxForge-0.1.1-Setup.exe

**普通用户请只下载这一个文件。** 这是 Windows 64 位 NSIS 安装包。

- 按向导安装：可以改安装目录，也可以选择仅为当前用户、或为这台电脑的所有用户安装（所有用户通常需要管理员权限）。
- 安装包内已包含：FFmpeg / ffprobe、LibreOffice（无界面 soffice）、Poppler（pdftoppm / pdftotext）、qpdf、Tesseract（简体中文 chi_sim + 英文 eng）、Pandoc、LibRaw（dcraw_emu）、Calibre（ebook-convert）、Sharp 图片引擎，以及人声分离用的 Demucs（CPU）与 UVR · MDX-Net（ONNX 模型）。
- 体积以本页面资源列表显示的为准（因内置完整引擎，会明显大于 v0.1.0）。
- 安装包尚未做代码签名，Windows 可能弹出 SmartScreen 提示，选择「仍要运行」即可。

「特殊音乐模块」仍是可选功能，不会变成就绪；应用内不附带任何加密音乐解密器。首次使用 Demucs 时，如尚未缓存对应模型权重，可能还会下载一次网络资源。

### FoxForge-0.1.1-Setup.exe.blockmap

分块校验文件，给自动更新使用。**手动安装不用下载。**

### latest.yml

自动更新元数据。**手动安装不用下载。**

## 许可说明

随包装入的第三方引擎仍保留各自的开源许可证（例如 FFmpeg、LibreOffice、Poppler、Tesseract、Pandoc、LibRaw、Calibre、PyTorch / Demucs 等）。请在遵守这些许可证的前提下使用与再分发。
